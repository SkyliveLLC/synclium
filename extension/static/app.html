Set up this device

  1. Choose where to sync

    A folder you already sync with iCloud Drive, Dropbox, or Syncthing. Each device picks the same folder.

    On another device, pick the same folder, or the Helium Sync folder inside it.

    Or use a WebDAV server: Nextcloud, ownCloud, Synology, Fastmail, Koofr

    Each device enters the same address. Synclium keeps its files in a Helium Sync folder there. The password is stored unencrypted in this browser.

  2. Sync key

    Everything in the store is encrypted with this key. Save it in your password manager: your other devices need it to join.

  3. Name this device

    Bookmarks and the last 90 days of history are stored in the folder or server, encrypted with the sync key.

Allow access

Synclium can't use your sync folder or server until you allow it again. Helium asks again for a folder after it restarts. Edits you make meanwhile are kept and sync once access returns.

For a folder, choose Allow on every visit in Helium's prompt so Synclium never asks again.

    Problems

      Review deletions

        Share this device's list of extensions with your other devices, and see what they have that this one doesn't. Nothing is installed for you: each one opens its Chrome Web Store page.

        Helium asks to let Synclium see your extensions. Turn it on on each device whose list you want to share.

          Tip: type hs and a space in the address bar to search from anywhere.

          Sync history

          Bookmarks and the last 90 days of history are stored in the sync folder, encrypted with the sync key.

          Sync key

          Another device needs this key to join. Anyone with it and the folder can read your bookmarks and history.

          Sync folder or server

          Choosing another folder or WebDAV server joins it as a new device. Bookmarks that already match are not duplicated.

          Full profile mode

          Also syncs settings, custom search engines, and addresses. A small companion app writes them into Helium's profile files after Helium quits, keeping a backup first. Protected settings, the default search engine, and cards are not synced.

          Helium's own guidance is not to modify these files. Turn this on only if you accept that.

          Helium asks to let Synclium talk to programs on this computer.

          Install the companion, then check again:

          The binary is companion/dist/helium-sync-companion from the repo build.

          Forget this device

          Deletes this device's files from the sync folder and its sync state here. Bookmarks and history in Helium stay as they are.
